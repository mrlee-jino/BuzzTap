# BuzzTap

BuzzTap is a business technology platform designed to provide smart and convenient technology solutions for businesses.

## Phase 1

BuzzTap Phase 1 is a frontend prototype built with:

- React
- Vite
- Tailwind CSS
- JavaScript

## Current Features

- Dashboard
- Workstations
- NFC Cards
- Transactions
- Customers
- Products & Services
- Reports
- Settings
